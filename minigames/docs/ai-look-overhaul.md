## 1단계 설계 메모

### 글꼴 (#2 · #21)

- 게임마다 **타이틀 글꼴 + 본문 글꼴** 두 벌. 웹이라 파일을 싣는데, 타이틀은 이름 글자만 남기는 서브셋이면 수 KB.
  본문 글꼴은 게임에서 쓰는 글자 전체가 필요하니 KS X 1001 완성형(2350자) + 영숫자 · 기호 서브셋을 기본으로(필요하면 한자 추가).
- 후보(전부 Google Fonts OFL — `https://raw.githubusercontent.com/google/fonts/main/ofl/<이름>/`):

| 아르카나 컬렉션 | Hahmlet(가변 굵기 800) · Gowun Batang Bold · 나눔명조 ExtraBold | Gowun Batang · Gowun Dodum |

### 타이틀 (#1)

- 자리 · 크기 상한은 같게, **처리는 게임 스타일로**: 젤리 = 지금(두꺼운 외곽선 · 그림자 · 들썩임), 스카이 = 얇은 청록 테 + 아래 선(HUD),
  러너 = 장난감 같은 두꺼운 테, 강호 = 외곽선 없는 먹색 + 낙관 자리, 아르카나 = 얇은 테 + 금빛 번짐, 제국 = 음각(위 어둡게 · 아래 밝게).
- `TITLE_COL` 대신 `UiKit.theme()` 에 `title_font` · `title_style` 을 둡니다.

### 단추 (#3 · #8)

- `UiKit.draw` 는 자리 · 마우스 판정 · 아이콘 · 글자 맞춤만 공통으로 두고, 몸통 그리기를 테마의 `btn_style` 로 갈래:
  `glossy`(젤리 — 지금 것) · `hud`(스카이 — 깎은 모서리 · 테두리만 · 들림 대신 밝기) · `toy`(러너) · `ink`(강호 — 먹선 테두리 · 종이 바탕 · 그림자 없음) ·
  `gild`(아르카나 — 금테 · 안쪽 테 하나) · `plate`(제국 — 각진 금속판 · 음각 글자).
- 숨 쉬는 빛 · 반짝임은 젤리 · 러너만. 나머지는 마우스 올림에만 반응.

### 모서리 (#4)

- `G2.round_rect(r, rad, kind := 0, corners := 0b1111)` — `kind` 0 원호(지금) · 1 부드러운 곡률(초타원 지수 4, 반지름 1.6배) · 2 깎음 · 3 안으로 파임.
  점 개수는 반지름에 비례(`max(6, rad * 0.6)`). `corners` 로 모서리 넷을 따로(탭은 위만, 붙은 단추 묶음은 바깥만).
- 안에 든 상자는 `안쪽 반지름 = 바깥 반지름 − 여백`.
- 게임 기본값은 테마의 `corner`: 젤리 1 · 스카이 2 · 러너 1 · 강호 0(작게) 또는 상자 없음 · 아르카나 3 · 제국 2.
- **부채꼴 채우기(`G2.fill_fan`) 규칙은 그대로** — 반지름이 높이의 절반일 때 꼭짓점이 겹치는 문제가 깎음 · 파임에서도 생기는지 확인.

### 글자 처리 (#7)

- `G2.text_mid` 의 외곽선 · 그림자를 일괄로 두지 말고, 밝은 그림 위의 글자에만. 패널 안 글자는 외곽선 없이 색 대비로.

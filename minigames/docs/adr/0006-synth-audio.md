# ADR-0006: 소리 · 음악은 전부 합성, 굽기는 나눠서

- **상태:** 채택 (지금 동작 기준, 2026-11-09)
- **층:** Presentation

## 결정
- 음원 파일 없음. 효과음은 켤 때 한 번 합성해 `AudioStreamWAV` 로 굳히고, 음 높이는 `pitch_scale` 로 바꿉니다.
- 배경 음악은 게임마다 따로(`Bgm.use("jelly"|"sky"|"runner"|"gangho"|"arcana")`, 허브는 젤리팝 곡).
- **굽기는 한 번에 한 곡, 프레임당 6ms.** 다른 곡 미리 굽기는 허브 화면에 있을 때만.
- 음량은 전체 · 효과음 · 배경음 세 막대(`Vol`). `Sv.music` · `Sv.sfx` 는 막대에서 따라오는 값.
- 테스트 빌드 · 명령줄 인자가 있는 실행은 전체 음량을 끕니다(`Vol.test_mute`, 저장값은 그대로).

## 결과
- 웹에서 첫 화면이 멎지 않습니다. 브라우저는 첫 터치 전엔 소리를 막으므로 시작 화면이 탭을 받습니다.

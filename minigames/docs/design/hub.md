# 허브 — 기획서

> **거꾸로 정리한 문서**(2026-11-09, 지금 동작 기준). "플레이어 경험" 줄은 추정이니 사용자가 확인해 주세요.

## 요약
앱을 켜면 뜨는 게임 고르기 화면. 게임 카드 다섯 장 중 하나를 누르면 그 게임의 처음 화면으로 갑니다.
앱이 꺼질 때까지 살아 있으면서 음악 · 음량 · 화면 크기 · 공통 단추를 맡습니다.

## 1. 개요
- 코드: `src/hub/` — `hub.gd`(카드 · 수명) · `bgm.gd` · `vol.gd` · `ui.gd`(`UiKit`) · `book.gd`(`UiBook`).
- 지키는 결정: [ADR-0002](../adr/0002-hub-lifetime.md) 수명 · [0003](../adr/0003-per-game-isolation.md) 공유 범위 · [0006](../adr/0006-synth-audio.md) 소리 · [0007](../adr/0007-screen-and-text.md) 화면 · [0008](../adr/0008-common-title-frame.md) 처음 화면 틀.

## 2. 플레이어 경험 (추정)
"뭐 하고 놀지" 를 1초 안에 고른다. 카드마다 그 게임의 그림이 살아 움직여서 고르기 전에 무슨 게임인지 안다.

## 3. 핵심 동작
- 카드 = 게임 하나(그림 `art/<게임>/<게임>_card.png`, 없으면 코드로 그린 미리보기 `_preview_*`).
- 게임 열기: 자식으로 붙임. 닫기: 게임이 `Hub.leave(self)`.
- 창 방향에 맞춰 캔버스 1280×720 / 720×1280(`_fit_canvas`).
- 허브에 있는 동안만 나머지 게임의 음악을 미리 굽습니다.

## 4. 조절값
`UiKit.theme`(게임별 색) · `UiKit.TITLE_COL` · `Hub.std_rect`(공통 단추 자리).

## 5. 합격 기준
- `run.bat -- --hub-test` 통과(다섯 게임 열고 닫기 + 두 게임 다시 열기).
- 새 게임을 넣으면 카드 · `--game=<id>` · `--hub-test` 순서에 같이 들어간다.

## 미결 질문
- 게임이 계속 늘어날 때 카드 배치(지금은 다섯 장 고정 배치인가?)와 앱 아이콘 · 로딩 화면(게임 수에 안 묶인 그림 — `art/GEN_NEXT.md` 보류).
- 젤리팝 카드 그림(`jelly_card`)만 아직 코드 미리보기.

# ADR-0004: 계산은 그리기를 모른다 — 헤드리스 검산으로 수치를 정한다

- **상태:** 채택 (지금 동작 기준, 2026-11-09)
- **층:** Core

## 맥락
난이도 · 분포를 감으로 잡았더니 별 셋이 불가능하거나(젤리팝), 무공을 배운 사람이 70% 가 되는(강호일생) 일이 났습니다.
봇을 수천 판 돌려 재려면 규칙 코드가 창 없이 돌아야 합니다.

## 결정
- 규칙 · 계산 클래스는 **그리기 · 시간 · 소리 · 저장 · 오토로드를 부르지 않습니다.**
  - 젤리팝 `Board` · `Play` · `StageGen` / 강호일생 `GhLife` · `GhRun` · `GhWorld` · `GhD` · `GhEv` / 아르카나 `AcGame` · `AcAi` · `AcD`.
- 화면(`main.gd`)은 그 함수를 애니메이션 사이에 **봇과 같은 순서로** 부릅니다.
- 검산: `check.bat`(젤리팝) · `tools/gangho_check.gd` · `tools/arcana_check.gd`. 실패하면 종료 코드 1.
- 수치를 만졌으면 창을 띄우기 전에 검산부터(사용자가 테스트 중 창을 껐다 켜는 것을 싫어함).

## 결과
- 월드 러너는 차례 진행이 `main.gd` 의 `await` 에 섞여 있어 규칙만 떼어 돌리지 못합니다. 대신 **자동 주행을 창 없이 큰 배속으로** 여러 판 돌립니다
  (`tools/runner_check.sh`, 11-09). 규칙을 `WrGame` 으로 옮기는 것은 차례 진행 800줄 · `await` 141곳이라 보류.
- 스카이 어설트는 아직 검산이 없고 자동 주행(`--autoplay`)만 있습니다.
- 2026-11-09 점검에서 세 검산 모두 통과.

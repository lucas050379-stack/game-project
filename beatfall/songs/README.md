# songs/

곡 하나 = 폴더 하나입니다. 게임이 **실행 중에 이 폴더를 읽습니다** — 곡을 더
넣는다고 다시 빌드할 필요가 없습니다.

```
songs/
└─ <곡 이름>/
   ├─ chart.json     채보 (제목 · BPM · 난이도별 노트)
   ├─ audio.ogg      곡 전체 (키음을 껐을 때 쓰는 것)
   ├─ bed.ogg        저음만 — 계속 흐르고 오디오 시계가 된다
   └─ keys.ogg       나머지 — 노트 시각으로 잘려 노트에 붙는다
```

`bed.ogg` 와 `keys.ogg` 가 **둘 다** 있어야 키음이 켜집니다. 없으면 `audio.ogg`
한 벌로 곡 전체를 통으로 재생합니다 — 옛 곡 폴더도 그대로 돌아갑니다.

곡을 넣으려면 상위 폴더에서:

```
import.bat "C:\어딘가\노래.mp4"
```

내보낸 exe 에서는 `beatfall.exe` 옆의 `songs/` 를 봅니다. 설치 폴더에 쓸 수 없는
환경(Program Files 등)에서는 `%APPDATA%\Godot\app_userdata\비트폴\songs\` 도 봅니다.

## chart.json

```json
{
  "title": "곡 이름",
  "artist": "만든 사람",
  "audio": "audio.ogg",
  "bed": "bed.ogg",
  "keys": "keys.ogg",
  "bpm": 128.0,
  "offset": 0.0,
  "charts": [
    { "name": "NORMAL", "keys": 4, "level": 7,
      "notes": [ [12.345, 2, 0.0], [12.6, 0, 0.75] ] }
  ]
}
```

- 노트 하나는 `[시각(초), 레인, 길이(초)]` 이고 길이 0 이면 그냥 누르는 노트입니다.
- **시각은 박이 아니라 초입니다.** `bpm` 은 화면의 격자 표시와 채보 생성기가
  참고할 뿐 재생에는 안 씁니다 — 실제 녹음은 BPM 이 미세하게 흔들려서, 박으로
  두면 곡 후반이 통째로 밀립니다.
- `offset` 은 곡 파일 앞에 붙은 무음입니다. 채보 전체가 일정하게 밀렸을 때
  여기를 고치면 한 번에 맞습니다.
- **노트는 시각 오름차순이어야 합니다.** 판정 루프가 앞에서부터 커서를 미는
  구조라 순서가 어긋나면 조용히 노트를 건너뜁니다.

손으로 고쳐도 됩니다. 게임을 다시 켜면 반영됩니다.

# ADR-0009: 저장은 게임마다 ConfigFile — 테스트 빌드는 파일을 나누고, 확인용 실행은 기록하지 않는다

- **상태:** 채택 (지금 동작 기준, 2026-11-09)
- **층:** Core

## 맥락
같은 주소(localhost)에서 정식 · 테스트 빌드를 띄우면 브라우저 저장소를 같이 씁니다.
확인용 실행이 저장을 해서 강호일생 기록 파일에 가짜 인생이 남은 적이 있습니다.

## 결정
- 게임마다 `user://<게임>.cfg`, 테스트 빌드(`testbuild` 태그)는 `user://<게임>_test.cfg`.
- 불러올 때는 값마다 형식을 확인하고 틀리면 기본값(깨진 파일로 멈추지 않음).
- **확인용 실행(명령줄 인자 · 자동 주행 · 캡처)은 기록 파일에 쓰지 않습니다**(`no_save` 또는 `get_cmdline_user_args().is_empty()`).

## 지키는 곳
- 강호 · 아르카나 `no_save`, 스카이 · 러너 `get_cmdline_user_args().is_empty()`, 젤리팝 `Sv.no_save`(11-09 — 그 전에는 확인용 실행이 실제 세이브에 썼음).
- 젤리팝 저장 파일 이름만 `save.cfg` / `save_test.cfg` 입니다(원본 그대로 — 바꾸면 기존 기록을 옮기는 코드가 필요해서 둠).

## 근거
CLAUDE.md "장치가 많아지면서 생긴 규칙"(testbuild) · 강호일생 확인용 실행 항목, 각 게임 `save.gd` · `rec.gd`.

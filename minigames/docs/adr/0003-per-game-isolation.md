# ADR-0003: 게임마다 접두어 · 폴더를 나누고, 공유는 앱 전체에 하나뿐인 것만

- **상태:** 채택 (지금 동작 기준, 2026-11-09)
- **층:** Foundation

## 맥락
갈루가와 젤리팝이 `Art` · `D` · `P` · `G2` 를 같이 써서 한 프로젝트에 넣자 열리지 않았습니다(Godot 의 `class_name` 은 프로젝트 전체에 하나).
게임마다 원본이 달라 서로 묶으면 한 게임을 고칠 때 다른 게임이 깨집니다.

## 결정
- 게임마다 **클래스 접두어**(`Sa` 스카이 · `Wr` 러너 · `Gh` 강호 · `Ac` 아르카나)와 **폴더**(`src/<게임>/` · `art/<게임>/`).
  젤리팝은 원본 이름 그대로(접두어 없음 — [review #2](../review-2026-11-09.md)).
- 허브(`src/hub/`)에는 **앱 전체에 하나뿐인 것만**: 음악(`Bgm`) · 음량(`Vol`) · 처음 화면 틀(`UiKit` · `UiBook`) · 수명(`Hub`).
- 리소스는 `minigames/` 안에서 자급자족 — 폴더만 복사해도 돕니다.

## 결과
- 비슷한 작은 함수(그림 불러오기 `img`/`art` 다섯 벌, 글자 그리기 `text_mid` 셋)가 게임마다 따로 있습니다. **의도된 중복**입니다 —
  다섯 줄짜리를 공유하려고 게임끼리 묶지 않습니다.
- 글꼴 · 기호 걸러 내기는 11-09 에 허브(`UiKit.font` · `UiKit.clean`)로 올렸습니다.
- **어긋난 곳:** 젤리팝의 `G2`(패널 · 둥근 사각형 · 부채꼴 · 글자 가운데 맞춤)를 허브 · 강호 · 아르카나 · 러너가 빌려 씁니다(130곳 남짓).
  사실상 앱 공용 도구가 젤리팝 안에 있는 셈입니다 — 젤리팝 접두어 정리([review #2](../review-2026-11-09.md))와 같이 허브로 옮길 후보.
- 새 게임은 새 접두어 · 새 폴더.

# ADR-0010: 온라인 순위는 젤리팝만 — 나머지는 기기 안 기록

- **상태:** 채택 (지금 동작 기준, 2026-11-09) — **넓힐지는 사용자 결정 대기**
- **층:** Feature

## 결정
- 젤리팝: 순위 · 플레이 기록이 사용자의 구글 시트(Apps Script, `tools/rank.gs`)로 갑니다. 주소(`rank_url.txt`)는 저장소에 안 올리고 CI 가 시크릿으로 씁니다.
  `Content-Type: text/plain`(OPTIONS 회피), 미리 받아 두기(`prefetch`), 테스트 · 확인용 실행은 안 보냄.
- 스카이(`SaRec`) · 러너(`WrRec`) · 아르카나(`AcSv`) · 강호일생(명예의 전당 `GhSv.hall`)은 **기기 안 기록**.

## 결과
- 처음 화면의 "순위" 메뉴 이름은 같지만 젤리팝만 다른 사람과 겨룹니다([review #8](../review-2026-11-09.md)).
- 넓히려면 `rank.gs` 를 게임 종류별로 고쳐 다시 배포해야 합니다.
- 서버는 숫자 범위 · 이름(시트 수식 앞머리) · 중복 사건을 거릅니다. 점수 위조는 막지 못합니다(장난 기록 감수).

## 근거
CLAUDE.md "웹이라서 지켜야 할 것"(순위), `tools/rank.gs`.

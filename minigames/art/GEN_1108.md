`--gh-tour` 의 `mate` 장면으로 중매 갈림길 위 초상을 확인한다. 아래는 그 전에 세운 계획 — 다시 뽑을 일이 있으면 참고.

**사용자가 보낸 참고 그림 수준을 원한다**(11-07: "이정도 퀄리티는 불가능할까?"). 참고 그림은 세로로 긴 상반신 ·
사실적인 얼굴 비율 · 섬세한 자수 · 손에 붓 · 부채 같은 소품 · 색동 테두리 · 크림색 한지 바탕의 **조선 한복** 미인화다.
지금 모델(`flux-1-schnell`)로 뽑은 여자 6종은 눈이 크고 인형 같으며, 옷이 중국풍이고, 엉터리 한자 · 낙관이 자주 들어간다.

1. **정할 것(사용자):** 옷을 참고 그림처럼 **한복**으로 할지, 배경(중원 무림)에 맞춰 **중국 옷**으로 할지.
2. **모델 비교:** 같은 프롬프트 하나(예: `gh_mate_f_1`)를 아래 모델에 2장씩 넣어 나란히 보여 주고 사용자가 고른다.
   Cloudflare 계정에 있는 텍스트→그림 모델(11-07 조회):
   `@cf/black-forest-labs/flux-1-schnell`(지금) · `flux-2-dev` · `flux-2-klein-9b` · `flux-2-klein-4b` ·
   `@cf/leonardo/lucid-origin` · `@cf/leonardo/phoenix-1.0` · `@cf/stabilityai/stable-diffusion-xl-base-1.0`.
   **위 모델은 한 장에 드는 뉴런이 몇 배다** — 비교는 모델당 2장으로 끝낸다. `gen_many.sh` 는 `MODEL` 이 고정이라
   모델마다 요청 모양(입력 이름 · 응답 형식)을 먼저 확인해야 한다.
3. **프롬프트(`@gmate`) 고칠 것:** 세로 구도(상반신 · 허리 위) · 사실적인 얼굴 비율(작은 눈 · 큰 눈 금지) · 손에 소품 ·
   자수 · 색동 테두리 · 한지 결. 고른 옷차림에 맞춰 옷 묘사를 다시 쓴다. 글씨 · 낙관 금지는 그대로.

## 2. 미니게임 모음 아이콘 · 로딩 화면 — **끝남(11-08)**

고른 것: `hub_icon_a` 04 · `hub_splash_a` 04 (`hub_splash_b` 는 "LEADING" 같은 가짜 글자가 박혀 탈락). `project.godot` 에
`config/icon` · `boot_splash/image` · `bg_color` · `stretch_mode=4`(cover) 연결함. 글자 얹기 · Windows .ico 는 안 함.
웹 셸은 cover 를 안 따르고 `object-fit: contain` + `bg_color` 로 띄운다 — 가로 화면에서 좌우는 바탕색 띠.

```
STEPS=8 bash art/gen_many.sh '^hub_(icon|splash)_' 4 4 8
```

| 이름 | 장면 |
|---|---|
| `hub_icon_a` | 보라 타일 위 2×2 — 젤리 · 전투기 · 주사위 · 수묵산 검객 |
| `hub_icon_b` | 젤리가 뜬 오락기 화면, 주위에 전투기 · 주사위 · 수묵산 |
| `hub_icon_c` | 선물 상자에서 튀어나오는 네 게임 |
| `hub_splash_a` | 보라 방 한가운데 빛나는 오락기와 네 게임 소품 |
| `hub_splash_b` | 별 하늘에 둥글게 뜬 네 개의 창, 가운데는 제목 자리 |

- 아이콘 셋 중 하나, 로딩 화면 둘 중 하나를 고른다.
- 고르기: **작게 줄여도 읽히는 것**(아이콘은 브라우저 탭에서 16px 로도 보인다), 네 게임이 다 보이는 것, 글자 없는 것.
- 후처리 `plain` → `art/jelly/hub_icon.png` · `hub_splash.png` 로 이름을 맞춘다.
- 연결(코드):
  - `project.godot` — `config/icon="res://art/jelly/hub_icon.png"`(웹 파비콘 · 창 아이콘이 이것을 쓴다).
  - `project.godot` — `[application] boot_splash/image="res://art/jelly/hub_splash.png"` · `boot_splash/bg_color` 를 그림 가장자리 색 ·
    `boot_splash/fullsize=false`(가운데 맞춤). 웹 내보내기의 로딩 화면도 이 그림을 쓴다 — 지금 뜨는 Godot 로고를 대신한다.
  - 로딩 그림에 **"미니게임" 글자**를 얹을지 정한다 — AI 는 한글을 못 쓰니 Jua 글꼴로 얹는 작은 도구(`tools/`)를 하나 만든다.
  - Windows exe 아이콘(`export_presets.cfg` 의 `application/icon`)은 .ico 가 필요하다 — 하려면 PNG 에서 만든다.
  - 확인: `build.bat` → `serve.bat` 로 브라우저에서 로딩 화면 · 탭 아이콘을 본다.

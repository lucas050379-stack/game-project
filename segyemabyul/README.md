# 세계마뷸 (World Marble)

Windows에서 **무설치 단일 exe**로 실행되는 세계마뷸 게임입니다.
`dist\segyemabyul.exe` 파일 하나만 있으면 됩니다. DLL·이미지·설정 파일이 전혀 필요 없습니다.

- 실행: `dist\segyemabyul.exe` 더블클릭
- 보드·국기·주사위·건물·캐릭터는 모두 코드로 그립니다 (외부 리소스 0개)
- Windows 10/11에 기본 포함된 .NET Framework 4.x 로 동작

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 클릭 | 버튼 선택, 우주여행 목적지 선택 |
| 마우스 올리기 | 도시 정보 툴팁 (소유자·통행료·건설비) |
| `Space` / `Enter` | 주사위 굴리기, 기본 버튼 확인 |
| `1` ~ `4` | 선택지 고르기 |
| `Tab` (또는 우측 상단 버튼) | 애니메이션 속도 x1 / x2 / x4 |
| `Esc` | 처음 화면으로 |

시작 화면에서 인원(2~4명)과 각 플레이어의 사람/AI를 바꿀 수 있습니다.
기본값은 사람 1명 + AI 3명입니다.

## 말과 랜드마크

말은 4명이 서로 다른 캐릭터입니다. 색만 다른 동그라미면 누가 누군지 안 붙습니다.

| 말 | 생김새 |
|---|---|
| **사람** | 붉은 베레모 · 금빛 **월계관 표장** · 물고 있는 **파이프 담배**(연기가 피어오름) |
| AI 1 | 가죽 비행모 · 이마에 올린 고글 (조종사) |
| AI 2 | 청록 두건 · 검은 뿔테 안경 |
| AI 3 | 뒤로 쓴 회색 캡 · 동그란 안경 · 경례하는 손 |

**사람은 항상 첫 번째 얼굴**을 씁니다. 슬롯 번호가 아니라 `Player.IsAI` 로 정하기 때문에
시작 화면에서 사람/AI를 바꿔도 내 말이 AI 얼굴이 되지 않습니다 (`Game.AssignFaces`).

랜드마크는 도시마다 다른 도안입니다 (`LandmarkKind` · `Icons.DrawLandmark`).

| | |
|---|---|
| 타이페이 101 · 마닐라 대성당 · 다이아몬드 헤드 | 머라이언 · 피라미드 · 블루 모스크 |
| 파르테논 · 콜로세움 · 알칼라 문 | 인어공주 · 돌하르방 · 스톡홀름 시청사 |
| 베른 시계탑 · 프라하 천문시계 · 수상 방갈로 | 브란덴부르크 문 · 성 바실리 성당 · 에펠탑 |
| 빅벤 · 오페라 하우스 · 자유의 여신상 | 도쿄 타워 · 남산 서울타워 |

도안은 모두 소유자 색으로 물들여 그리므로, 모양이 달라도 **누구 것인지는 색으로 읽힙니다.**

## 화면에서 내 것 찾기

칸이 32개라 색만 옅게 입히면 누가 어디를 먹었는지 묻힙니다. 세 가지로 나눠 표시합니다.

| | 표시 |
|---|---|
| **내 말 위치** | 말이 AI보다 **약 1.15배** 큽니다. 모든 말은 둘레에서 **태양처럼 뾰족한 불꽃**이 뻗어 나오며, 색은 그 플레이어 색이라 누구 말인지도 같이 읽힙니다. 가시마다 길이가 따로 늘었다 줄어듭니다. |
| **점유한 땅** | 칸 안쪽(판 여백)에 소유자 색 **띠**가 깔립니다. 옆 칸과 이어져 보여서 누가 어디까지 먹었는지 한 줄로 읽힙니다. 여기에 칸 전체 색조와 테두리가 더해집니다. |
| **내 땅** | AI 땅보다 띠가 굵고 발광하며, 테두리도 더 두껍습니다. |

띠를 칸 **바깥**에 그리는 이유는 국기·도시 이름·통행료를 가리지 않기 위해서입니다.
`Render.DrawClaimBar` 가 `Board.GridPos` 로 그 칸이 판의 어느 변에 있는지 보고
안쪽을 향한 방향에 띠를 놓습니다.

> 광선은 `Icons.SunRays` 가 그립니다. 안쪽 반지름과 가시 끝을 **번갈아 찍어** 각이 진
> 별 모양을 만듭니다 — 매끄러운 파형으로 둘레를 흔들면 진폭을 아무리 키워도
> "울렁이는 원"으로 보이지 가시로는 안 보입니다. 가시마다 위상이 달라 따로 뻗었다 오므라들고,
> 길이·개수·회전 방향이 다른 세 겹을 겹쳐 태양 코로나처럼 만듭니다.
>
> **원반이나 원형 테두리는 두지 않습니다.** 가시와 따로 놀아 이질감이 생깁니다.
> 대신 가시를 진하게(안쪽 겹 알파 195) 뽑아 그 몫까지 맡깁니다.
> 밝기는 **완전히 꺼지지 않고** 최대치의 0.5~1.0 사이만 오르내립니다 — 0 까지 내리면 깜빡여 보입니다.
>
> 불꽃 색은 **흰색이 아니라 플레이어 색**입니다. 칸 바탕이 거의 흰색이라 흰 불꽃은
> 소유되지 않은 칸 위에서 대비가 거의 없습니다. 플레이어 색이면 어느 칸에서도 보이고,
> 누구 말인지까지 한 번에 읽힙니다.

## 규칙

보드는 **9×9 격자의 테두리 = 32칸** (모서리 제외 한 변에 7칸)입니다.
각 변은 아래 두 패턴을 번갈아 사용합니다.

```
하단  도시 특수 도시 특수 도시 도시 도시      (A형)
좌측  도시 도시 도시 특수 도시 특수 도시      (B형)
상단  도시 특수 도시 특수 도시 도시 도시      (A형)
우측  도시 도시 도시 특수 도시 특수 도시      (B형)
```

- 한 변에 도시 5곳 — **한쪽 2곳이 한 색 / 다른쪽 3곳이 다른 색** (총 8개 대륙 그룹: 2도시 4개 + 3도시 4개)
- **색이 바뀌는 경계에는 반드시 특수칸 또는 모서리**가 들어감
- **각 변의 첫 칸과 마지막 칸은 항상 도시**
- **특수칸끼리, 특수칸과 모서리끼리 절대 붙지 않음** — 모든 특수칸은 도시 사이에 있습니다

전체 구성은 도시 20곳 · 관광지 3곳(하와이·제주도·몰디브) · 황금열쇠 3칸 ·
사회복지기금 1칸 · 국세청 1칸 · 모서리 4칸입니다. 금액 단위는 만원입니다.

- **시작 자금** 200만원, **출발 통과** +20만원, **출발 칸 정확히 도착** +40만원
- **건설 5단계**: 토지 → 별장 → 빌딩 → **호텔** → **랜드마크**
  - **호텔까지는 도착한 그 자리에서 바로** 연속 건설 가능
  - **랜드마크는 두 가지 경로**로 세웁니다. 통행료가 매입가의 약 2.9배로 뛰며, 독점까지 겹치면 두 배가 됩니다
    1. 호텔을 보유한 도시에 **다시 도착**했을 때
    2. **출발 칸에 정확히 도착**했을 때 — 호텔이 선 내 도시 목록에서 하나를 골라 올립니다
       (여러 곳이면 통행료가 가장 많이 오르는 4곳을 보여줍니다)
  - 랜드마크는 도시마다 **실제 그 도시의 명소 모양**으로 세워집니다 —
    파리는 에펠탑, 서울은 남산타워, 카이로는 피라미드처럼 23종이 각각 다릅니다
- **통행료 2배 지역**: 게임 시작 시 무작위 **2곳**이 지정되어 그 칸의 통행료가 항상 2배가 됩니다.
  대륙 독점(2배)과 겹치면 **4배**까지 올라갑니다. 칸에 빨간 `통행료 2배` 표시와 붉은 발광이 붙습니다
- 한 **대륙의 도시를 모두 소유**하면 그 대륙 통행료 **2배**
- **관광지**(하와이·제주도·몰디브)는 건물 건설 불가, 통행료 = 8만 × 보유 관광지 수 (3곳 모두 보유 시 24만)
- **도시 인수**: 남의 도시에 도착해 통행료를 낸 뒤, 총투자액의 2배를 지불하면 인수 가능.
  **랜드마크가 세워진 도시는 인수할 수 없고**, 소유자가 매각하는 것만 가능합니다 (호텔까지는 인수 가능)
- **무인도**: 3턴 정지. 더블이 나오면 즉시 탈출, 탈출권이 있으면 사용 가능
- **우주여행**: 도착하면 그 턴은 즉시 종료되고(더블이어도 추가 주사위 없음),
  다음 턴에 주사위 대신 원하는 칸을 골라 **진행 방향으로 그 칸까지 이동**합니다.
  이동 중 출발 칸을 지나면 급여를 받습니다
- **황금열쇠**: 18종 카드 (이동 · 수입 · 지출 · 무인도 · 탈출권 · 기금 등).
  이동 카드는 순간이동이 아니라 **진행 방향으로 목적지까지 이동**하며, 도중에 출발 칸을 지나면 급여를 받습니다
  (무인도 추방 카드만 즉시 이송이라 급여가 없습니다)
- **사회복지기금**: 납부 칸에서 15만원 적립, `기금 수령` 칸에 도착하면 적립금 전액 획득
- **국세청**: 보유 현금의 10% 납부 (기금으로 적립)
- **더블**: 한 번 더 굴림. 3연속 더블은 무인도로 추방.
  단 무인도에 갇히거나 우주여행 칸에 도착하면 더블이어도 그 턴은 즉시 끝납니다
- **현금 부족** 시 매각 — 선택한 도시의 **건물과 토지가 한 번에 처분**되며 총투자액의 50%를 회수합니다.
  더 팔 자산이 없으면 파산
- 마지막 1명이 남으면 승리. 40라운드가 지나면 총자산이 가장 많은 플레이어 승리

## 직접 빌드하기

Visual Studio나 .NET SDK 없이 Windows 내장 컴파일러로 빌드합니다.

```
build.bat
```

`dist\segyemabyul.exe` 가 생성됩니다.

## 소스 구성

| 파일 | 내용 |
|---|---|
| `src/Program.cs` | 진입점 |
| `src/Data.cs` | 보드 32칸 · 규칙 상수 · 황금열쇠 카드 |
| `src/Game.cs` | 게임 상태와 규칙 계산 (통행료, 독점, 자산, 파산) |
| `src/Ai.cs` | AI 판단 (매입 · 건설 · 인수 · 우주여행 목적지 · 매각) |
| `src/GameForm.cs` | 60fps 루프, 트윈 엔진, 턴 진행 흐름, 입력 |
| `src/Render.cs` | 레이아웃과 화면 렌더링 |
| `src/Effects.cs` | 파티클 · 코인 이동 · 플로팅 텍스트 · 화면 흔들림 |
| `src/Icons.cs` | 국기 · 주사위 · 건물 · 캐릭터 · 특수칸 아이콘 벡터 드로잉 |
| `src/Util.cs` | 이징 · 색상 · 도형/텍스트 헬퍼 |

# 미니게임 모음 (Minigames)

Godot 4 / GDScript · **웹(브라우저) 앱 하나**에 게임 다섯이 들어 있습니다. 처음 화면(허브)에서 고릅니다.

| 게임 | 장르 | 출처 |
|---|---|---|
| **젤리팝** | 3매치 퍼즐 — 모험 200판 · 60초 타임 어택 | 젤리팝 원본(지금은 저장소에서 뺌)을 그대로 옮김 · 자세한 문서는 [JELLYPOP.md](JELLYPOP.md) |
| **스카이 어설트** | 세로 슈팅 — 기체 7종 · 라운드 6개 · 보스 부위 파괴 | 갈루가(지금은 저장소에서 뺌)를 **세로 화면 · 터치**로 옮기고 이름을 바꿈 |
| **월드 러너** | 주사위 보드게임 — 세계 도시를 사고 지어 상대를 파산시키기 | 세계마뷸(C# WinForms, 지금은 저장소에서 뺌)을 **GDScript 로 새로 씀** |
| **강호일생** | 무협 인생 시뮬레이션 — 태어날 자리는 무작위, 갈림길 · 할 일 · 인연으로 일생을 기울임 | **새로 만듦**(원본 없음) |
| **비술난무** (작업 중) | 횡스크롤 커맨드 액션 — 방 단위 지형, 띄우기 · 공중 연타, 기술 다섯 | **새로 만듦** — 이펙트는 [pixelfx](https://github.com/patch-gg/pixelfx)(MIT)로 구움 |

원본 세 게임은 11-08 에 저장소에서 뺐습니다(git 기록에는 남음). 이 폴더는 그것들을 **복사해 와서** 한 앱으로 묶은 것이고,
저장소 규칙대로 이 폴더만 복사해도 혼자 돕니다.

```
run.bat                   소스에서 실행 (허브부터)
build.bat                 정식판   → dist\web\ + dist\minigames.exe
build-test.bat            테스트판 → dist\web-test\ + dist\minigames-test.exe (젤리팝 전부 열림 · 세이브 따로 · 소리 꺼짐)
serve.bat [test]          웹 빌드를 localhost:8060 (test 는 8061) 에 띄움
check.bat                 젤리팝 판 로직 · 스테이지 검사
```

## 확인용 실행

| 명령 | 하는 일 |
|---|---|
| `run.bat -- --hub-test` | 젤리팝 → 스카이 어설트 → 월드 러너 → 강호일생 → 젤리팝 → 강호일생을 열고 닫는다. 다시 열 때 깨지는 것(지운 노드를 가리키는 소리 · 순위 노드)을 잡는다 |
| `run.bat -- --ui-test` · `--input-test` | 젤리팝 — 진짜 클릭으로 화면을 돈다 · 진짜 끌기로 바꾼다(음량 창 열고 닫기 포함) |
| `run.bat -- --game=sky --touch-test` | 스카이 어설트 — 진짜 터치로 출격 → 끌기 → **끄는 채로** 스킬 누르고 떼기 → 봄 → 그만하기 |
| `run.bat -- --game=runner --runner-auto` | 월드 러너 — AI 넷이 한 판을 끝까지(×16 속도) |
| `run.bat -- --game=runner --runner-auto-human` | 〃 0번 자리는 사람 — 창 · 단추 · 칸 고르기를 대신 눌러 **사람 쪽 경로**까지 돈다 |
| `run.bat -- --autoplay [--round=N --prog=0.5]` | 스카이 어설트 무인 주행(갈루가의 soak 와 같음) |
| `run.bat -- --game=gangho --gh-click-test` | 강호일생 — 진짜 클릭으로 처음 → 태어나기 → 삶 → 배속 · 자동 · 멈춤 → 갈림길 → 동년배 · 할 일 · 인연 창 → 나가기 → 지난 인생 |
| `run.bat -- --game=gangho --gh-auto` | 강호일생 — 갈림길을 성향대로 고르며 한 일생을 끝까지(×20 빨리) |
| `godot --headless --path . --script res://tools/gangho_check.gd -- 2000` | 강호일생 검산 — 창 없이 2000번 태어나 수명 · 무공 비율 · 경지 · 갈림길 수 · 칭호 분포를 찍고, 글자 자리가 남은 줄이나 끝나지 않는 인생이 있으면 실패 |
| `godot --headless --path . --script res://tools/mystic_check.gd -- 6` | 비술난무 검산 — 창 없이 커맨드 다섯이 서로 오인 없이 읽히는지, 봇이 세 스테이지(방 · 보스)를 끝까지 가는지 |
| `run.bat -- --game=mystic --ms-auto` | 비술난무 — 봇이 스테이지를 끝까지(`--shot=out.png --shot-at=3,9,20` 으로 여러 장 캡처) |
| `--game=jelly\|sky\|runner` | 허브를 건너뛰고 그 게임부터 |
| `--hub-shot=a.png --hub-shot-at=1.5` · `--shot=` · `--vol` · `--peek=N` | 캡처용(허브 · 각 게임 · 음량 창 · 월드 러너 N번 칸 도시 카드) |

**명령줄 인자가 하나라도 있으면(그리고 테스트 빌드면) 전체 음량을 끄고 돕니다**(`Vol.test_mute`).
저장된 음량은 건드리지 않습니다.

## 구조

```

src/hub/           허브(게임 고르기) · 배경 음악(Bgm) · 음량 창(Vol)
src/jelly/         젤리팝 (클래스 이름 원본 그대로: Art · D · P · G2 · Board · Play · Sv · Snd …)
src/sky/           스카이 어설트 (갈루가 클래스에 Sa 를 붙임: SaArt · SaD · SaP · SaG2 · SaHud · SaSel · SaWorld)
src/runner/        월드 러너 (Wr: WrD · WrGame · WrAi · WrIcons · WrFx)
src/gangho/        강호일생 (Gh: GhD · GhEv · GhWorld · GhLife · GhRun · GhArt · GhSv · GhSnd) — 계산(life · run · world)은 그리기를 모른다
font/              글꼴(Jua) — 셋이 같이 쓴다

art/               생성 도구(gen.bat · post.bat · prompts.txt)와 후보 원본(source/, git 제외)은 셋이 같이 쓴다
```

### 허브

- **허브는 앱이 꺼질 때까지 살아 있고 게임 화면만 갈아 끼웁니다.** `change_scene` 으로 장면을 통째로
  바꾸면 효과음 · 배경 음악 · 순위 요청이 붙어 있던 노드가 같이 지워져, 다시 열 때 static 변수가 지운
  노드를 가리킵니다. 오래 사는 것은 `Hub.host(self)` 로 허브에 붙이고, 게임에서 나갈 때는 `Hub.leave(self)`
  하나만 부릅니다(허브 없이 단독으로 돌면 그냥 끝냅니다).
- **클래스 이름은 프로젝트 전체에서 하나입니다.** 갈루가와 젤리팝이 `Art` · `D` · `P` · `G2` 를 같이 써서
  그대로는 프로젝트가 열리지 않았습니다. 게임마다 접두어(Sa · Wr)를 붙였습니다 — 새 게임도 그렇게 하세요.
- **화면 글자에 `·` `—` `×` `→` 를 쓰지 마세요**(Jua 에 없어서 웹에서 네모). 스카이 어설트는 원본 글이
  이런 기호를 많이 써서 `SaG2.clean` 이, 월드 러너는 `WrIcons.clean` 이 그릴 때 바꿉니다.

### 소리

- **배경 음악은 게임마다 따로입니다**(`src/hub/bgm.gd`) — 젤리팝(허브도 이 곡) C 장조 마림바 112 BPM,
  스카이 어설트 A 단조 150 BPM(8분 베이스 · 킥/스네어 · 파워 코드 · 톱니 리드),
  월드 러너 F 장조 104 BPM(튜바 쿵짝 · 뜯는 화음 · 글로켄). 전부 합성이라 음원 파일은 없습니다.
  게임은 `_ready` 에서 `Bgm.use("sky")` 처럼 자기 곡을 고르고, 허브로 돌아오면 젤리팝 곡입니다.
- **굽기는 한 번에 한 곡, 프레임마다 6ms 씩**입니다(웹에서 한 번에 구우면 화면이 멎습니다). 고른 곡이
  먼저이고, **허브 화면에 있을 때만** 나머지 곡을 미리 구워 둡니다 — 게임 중에 굽기를 더하면 프레임을 먹습니다.
- **음량 창(`Vol`) — 전체 · 효과음 · 배경음.** 허브와 젤리팝 처음 화면의 "음량" 단추로 엽니다. 전체는
  Master 버스, 나머지는 각 플레이어 볼륨입니다. 예전 켬/끔 깃발(`Sv.music` · `Sv.sfx`)은 **막대 값에서
  따라옵니다**(0 이면 끔) — 효과음 · 배경음 코드가 그 깃발을 보므로 둘이 따로 놀면 "막대는 올렸는데 소리가
  안 난다"가 됩니다. 예전 세이브에서 꺼 둔 것은 0 으로 옮깁니다.

### 모바일 크기

**기본은 가로 1280×720**입니다(11-04). 허브가 창 방향을 보고 기준 캔버스를 가로 1280×720 · 세로 720×1280 으로
바꿔서(`Hub._fit_canvas`) **짧은 변은 언제나 720** 입니다. 게임마다 `wide()` 로 갈라 가로면 좌우 정보창 배치
(젤리팝: 판 가운데 · 이동/미션 왼쪽 · 점수/별 오른쪽, 스카이 어설트: 필드 가운데 세로 띠 · 정보와 단추 좌우,
월드 러너: 상태창 네 모서리), 세로면 예전 배치입니다. 젤리팝 판은 열린 칸 밑에 판 바탕(`_draw_board_base`)을 깝니다.

짧은 변 720 은 폰(약 360dp)에서 **절반 크기로 보입니다.** 그래서 캔버스 20px 미만 글자는
폰에서 10dp 아래로 내려가 읽기 힘듭니다. 스카이 어설트 · 월드 러너의 글자는 이 기준으로 다시 잡았습니다
(PC 캡처 450×800 창에서는 여전히 작아 보입니다 — 실제 폰 비율과 같습니다).

## 스카이 어설트 (갈루가 → 세로)

- **월드는 그대로 논리 폭 384 이고, 화면에는 배율 `k` 로 키워 그립니다**(`main.gd` 의 `field.scale`).
  폭을 720 으로 늘리면 탄 속도 · 판정 · 보스 체력이 전부 틀어져 "넓어서 걸어서 피해지는" 다른 게임이 됩니다.
  논리 높이는 화면 비율에 따라 `SaD.PLAY_H_MIN`(600) 이상으로 정해집니다 — 갈루가도 창 높이를 그대로 썼습니다.
- 갈루가의 좌우 패널은 **위 점수 띠 · 아래 단추 띠**로 나눴습니다(`SaHud.top_bar` · `controls`).
  플레이필드 안에는 보스 막대 말고 아무것도 겹치지 않습니다.
- **조작은 끌기 · 스킬 단추(누르고 있다 떼기) · 봄 단추.** 스킬을 누른 채 다른 손가락으로 끌어야 하므로
  **멀티터치를 직접 받습니다** — 젤리팝이 쓰는 터치→마우스 흉내는 첫 손가락 하나만 넘깁니다. 흉내 낸
  마우스 이벤트는 `device == DEVICE_ID_EMULATION` 으로 걸러 두 번 처리하지 않습니다.
- **끌기는 상대 이동 1:1 이고, 한 프레임에 기체 속도의 `DRAG_MUL`(3) 배까지만** 갑니다. 넘친 만큼은
  **버리지 않고 다음 프레임으로 넘깁니다**(`DRAG_CARRY` 까지) — 버렸더니 빠르게 그은 손가락을 기체가
  못 따라왔습니다.
- 발광은 갈루가처럼 `hdr_2d` + 글로입니다. 화면 설정이라 이 게임에 들어올 때 켜고 허브가 닫을 때 끕니다.
- 테스트 빌드 판정은 `testbuild` 태그(젤리팝과 같음)입니다. 소스 실행은 디버그 빌드라 라운드 줄 · `B` 가 켜집니다.

## 월드 러너 (세계마뷸 → GDScript)

- 규칙 · 수치 · AI 는 원본과 같습니다(`data.gd` · `game.gd` · `ai.gd` ↔ `Data.cs` · `Game.cs` · `Ai.cs`).
  규칙 설명은 [segyemabyul/README.md](../segyemabyul/README.md) 를 보세요.
- **턴 진행은 원본 `async/await` 를 GDScript `await` 로 줄 단위로 옮겼습니다.** `await tween(...)` ·
  `await _ask(...)` 가 그 자리에서 기다립니다. **판을 도중에 버릴 때는 `_reset()` 하나만** 부르세요 —
  기다리던 트윈 · 단추 · 창을 비우면 매달려 있던 진행 함수가 다시 깨어나지 않고 사라집니다.
- **람다는 지역 변수를 값으로 잡습니다.** 트윈 안에서 바꿔야 하는 값은 배열에 담습니다(`_jump_to` 의 `last`).
- 그림(`icons.gd`)은 GDI+ 의 `FillEllipse(x, y, w, h)` · `FillPie` 식 헬퍼(`fe` · `fpie` · `fr` · `fp` · `ln`)로
  원본 좌표를 그대로 옮겼습니다. **GDI+ 는 꼬인 다각형도 칠하지만 Godot 는 조용히 안 그립니다** — 도쿄 타워 ·
  에펠탑 다리가 그랬습니다. `fp` 는 분할이 안 되면 볼록 껍질로 칠합니다. 새 도형을 넣었으면 `--runner-auto`
  를 돌려 stderr 에 `triangulation failed` 가 없는지 보세요.
- **변환은 `WrIcons.push` / `pop` 으로만** 겁니다. `draw_set_transform` 은 덮어쓰기라 화면 흔들림(`base`)을
  늘 앞에 곱해야 판과 말이 따로 흔들리지 않습니다. 허브처럼 다른 곳에서 빌려 그릴 때는 `set_base` 로 먼저 비웁니다.
- 세로 화면에 맞춰 **위 판(9×9) + 아래 플레이어 카드 2×2**. 원본의 마우스 올리기 정보는 **칸을 눌러** 띄웁니다
  (터치에는 올리기가 없습니다). 칸이 폰에서 손톱만 해서 **국가명 줄은 칸에서 빼고** 이름 · 통행료를 키웠습니다
  — 국가명은 정보창 · 도시 카드에 있습니다.
- 원본의 제약(내 말은 크기로만 구분 · 둘레 표시는 태양 광선뿐 · 명멸은 0.5~1.0 · 소유 띠는 칸 바깥 · 얼굴은
  `IsAI` 로 · 랜드마크 도시마다 다름 · 출발 칸 랜드마크는 목록에서 고르기)은 그대로 지켰습니다.
- **그림(`art/runner/`)이 있으면 그림, 없으면 벡터**(`WrIcons.art`). 말은 판 위에서 전신(칸보다 크다), 패널에서는
  얼굴 부분만 잘라 씁니다. 그림 말은 태양 광선 대신 실루엣 오라 · 옷은 플레이어 색입니다. 고른 후보는
  [art/runner_picks.txt](art/runner_picks.txt), 마무리는 `tools/runner_art.gd`(랜드마크 회색 · 옷 마스크 · 오라).
- **모서리 칸은 다른 칸보다 5% 크게** 그립니다(`cell_diamond`). 클릭 판정 · 판 좌표는 그대로입니다.
- **판을 끌면 시야가 옮겨지고 휠로 확대 · 축소합니다.** 옮긴 시야는 말이 움직이거나 차례가 바뀌면 다시 말을 따라갑니다.

## 강호일생 (새로 만듦)

무협 세계의 **인생 시뮬레이션**입니다. 태어날 시대 · 땅 · 집안 · 성별 · 근골 · 오성을 고를 수 없고, 한 해씩 흘러가는
일생을 갈림길에서만 고릅니다. 같은 해 태어난 동년배 넷이 같은 세상(흉년 · 역병 · 정마대전 · 비무대회)을 나란히 삽니다.
『80억분의 1』 같은 무작위 인생 장르를 무협으로 새로 설계한 것입니다(사용자 요청 11-06).

- **천하 사람 대부분은 무공을 모릅니다.** 농가 · 소작이 절반이 넘고, 무공에 닿는 사람은 30% 안팎입니다.
  출생 표를 무림 쪽으로 기울이면 "누구로 태어나느냐" 가 사라져 그냥 무협 육성 게임이 됩니다.
- **세력:** 구파일방(소림 · 무당 · 화산 · 아미 · 곤륜 · 점창 · 청성 · 종남 · 공동 + 개방) · 오대세가(남궁 · 모용 · 제갈 · 당 · 팽) ·
  천마신교 · 새외오궁(북해빙궁 · 포달랍궁 · 남만야수궁 · 천산설궁 · 남해신궁) · 사파 다섯 · 관군 · 표국.
- **진로를 기울이는 넷**(인물 판 아래 "방침" 단추, 키 `P` — 탭 셋):
  - **방침** 여섯 중 하나(생업 · 건강 · 학업 · 무예 · 장사 · 견문 우선) — 원작의 "건강 우선 · 일 우선 · 학업 집중" 자리.
  - **매년 하는 일** 여럿(가족 나들이 · 저녁 식사 · 자식 용돈 · 부모 봉양 · 무관 · 벗과 술자리 · 시주) — 해마다 돈이 들고, 모자라면 거른다.
  - **지금 하기**(각각 한 해에 한 번) — 가족 여행 · 한턱 · 용돈 · 선물 · 의원 · 술 한잔 · 문파 찾아가기(평생 세 번) · 과거 · 혼처 · 비무 · 장터 ·
    **전장에서 돈 빌리기 · 빚 갚기**. 빌리는 돈과 한도는 신용(집안 · 명성 · 벼슬 · 재물 · 심성 · 갚은 이력)으로 정하고, 이자는 해마다 1할,
    못 갚으면 독촉 · 야반도주가 온다.
  - **배움**(한 번에 하나, 여러 해) — 의술 · 상단 견습 · 대장일 · 표국 견습 · 무과 준비 · 약초학 · 역술 · 서화 · 출가 · 내공 심법.
    마치면 자격이 남고 전직 갈림길이 뜬다(원작의 자격증 · 대학 자리).
  - **글공부는 사다리**(원작의 초 · 중 · 고 · 대학 진학 자리, 11-07): 일곱 살에 서당에 다닐지 묻고 → 서당을 떼면 향교에 갈지 →
    향교를 마치면 **동시**(붙으면 수재) → 서원에 갈지 · 훈장이 될지 → 서원을 마치면 **향시**(거인) → 벼슬길에 나설지 · 국자감에 갈지 →
    국자감을 마치면 **회시**(진사, 벼슬 두 계단). 떨어지면 이듬해 다시 볼지 묻고, "지금 하기" 의 과거로도 다음 시험을 본다
    (맞는 배움을 안 마쳤으면 확률 절반). 벼슬은 거인부터. 훈장은 수재부터. 2000번 중 수재 10% · 거인 4% · 진사 2%, 벼슬 6%.
  - **직업** 26종 — 일꾼 · 점소이 · 사공 · 이야기꾼 · 훈장 · 문사 · 책사 · 역관 · 객주 · 의원 · 약초꾼 · 대장장이 · 화공 · 점쟁이 · 도사 · 승려 ·
    도박사 · 정보상 · 포졸 · 포쾌 · 무관 · 표사 · 낭인 · 무관 사범 · 살수. 조건(배움 · 경지 · 근골 · 오성 · 심성)이 맞으면 직업 탭에서 바로 바꾼다.
    직업마다 벌이 · 진로 배수 · 전용 사건(살수의 청부 · 포쾌의 추적 · 책사의 계책 …) · 칭호가 붙는다.
- **타고난 것 다섯:** 근골 · 오성 · 매력 · 손재주 · 수완(1~100) + 운(1~10). 직업마다 기대는 스텟이 다르고(`GhD.JOB_RANKS` 의 `stat`),
  태어날 때 **어울리는 길** 셋(`GhLife.suited_jobs`)과 직업 탭의 **적성 높음 / 보통 / 낮음**(`aptitude`)이 그 스텟으로 매겨진다.
  적성이 높을수록 그 일의 단을 넘는 벽이 쉽다. 근골 · 오성만 있던 시절에는 무엇이 왜 추천되는지 알 수 없었다.
- **무협의 결:** 드문 체질(천골지체 · 금강지체 · 만독불침지체 · 천음절맥), 경지가 오를 때 몸이 바뀌는 순간(검기 → 임독양맥 → 생사현관 → 이기어검),
  무공 갈래(검 · 도 · 권장 · 경공 · 암기 · 독 · 음공 · 진법 · 내공 — 비무 힘과 진로 배수에 들어감), 폐관수련(8년에 한 번), 명성 · 악명 · 관부 신망 세 갈래,
  강호에 이름이 나면 붙는 **별호**(무공 갈래 · 심성 · 경지로 짓고, 무림인이 아니면 직업으로 — 신의 · 도신 · 와룡선생 …). 직업은 41가지.
- **인생의 갈림길 — 위험과 보상**(`GhEv.RISK` 20종): 분점 내기 · 빚내서 확장 · 큰 납품 · 맞은편 상단 · 동업 · 보호비 · 독립 · 상경 ·
  윗자리 다툼 · 전직 · 역병 고을 · 무리한 운기 · 금지 마공 · 개파 · 고수 도전 · 황자 줄서기 · 남양 무역 · 의병 · 운하 땅.
  안전한 쪽은 조금 얻고, 무리한 쪽은 **자리**가 바뀐다 — 사업이 두 단 커지거나 통째로 넘어가고, 일의 단이 오르거나 내려가고,
  일자리를 잃고, 몸이 상하고, 문파를 열거나 파문당한다.
- **돈은 벌기만 하지 않는다:** 해마다 수입이 출렁이고(0.55~1.45배), 생활비가 나간다(식구 수 × 사는 수준 — 빈궁 · 소박 · 넉넉 · 부유 · 호화,
  부자일수록 씀씀이가 큼). 해마다 13% 남짓 뜻밖의 지출(병원비 · 도둑 · 화재 · 사기 · 빚보증 · 송사)이 오고 크기는 가진 돈에 비례한다.
  사업은 해마다 망할 수 있다(키울수록 위험). 모자라면 굶어 건강이 깎인다. 가만히 산 사람의 마흔 넘어 재산: 25% 43냥 · 중앙 236냥 ·
  90% 948냥, 빈털터리 19%. 적극적으로 산 사람: 중앙 1,683냥 · 90% 9,302냥, 빈털터리 8%.
- **천마신교 혈통:** 서역 본교에서만 태어나는 신교 장로가(세가급)와 교주 혈통(소교주 — 황족보다 드묾). 소교주는 이복형제 암투 · 정파 자객을 겪고
  살아남아 절정을 넘기면 천마로 즉위한다(칭호 "천마"). 서출은 적통에게 반기를 들 수 있다.
- **시대:** 난세 / 태평성대(그 해를 가운데 둔 20년의 난리 수)가 진로 배수를 바꾼다. 무림맹 결성 · 마교 분열 · 이민족 침입 · 해적도 세상 일로 든다.
- **동년배 라이벌:** 같은 문파 동년배와 장문인 자리를 두고 비무, 정 · 사로 갈린 동년배는 숙적이 되어 몇 해마다 다시 맞붙는다(드물게 한쪽이 죽는다).
  정든 사람이 동년배일 수 있고, 떠나보낸 첫사랑의 혼인 소식이 온다. 동년배의 큰일은 한 해에 하나씩 "소식" 으로 들린다.
- **무공:** 문파마다 4~7개 + 절세 무공 하나(장문인 · 가주 · 그 문파에서 얻은 기연 · 화경). 익힌 가짓수와 절세 무공이 비무의 힘에 더해진다.
- **도감 · 명예의 전당**(처음 화면): 출생 도감 23집안(세가 다섯을 따로), 칭호(특별 칭호 15개는 자물쇠), 경지 · 재산 · 장수 · 명성 위 다섯.
  온라인 순위는 아직 없다 — 젤리팝 순위 서버(tools/rank.gs)가 젤리팝 점수 전용이라 서버를 고쳐 다시 배포해야 한다.
- **처음 하는 사람 안내:** 첫 판에 한 번씩 짧은 안내가 뜬다(시간은 안 멈춤 · 누르면 닫힘 · `GhSv.tips`).
- **가세 · 차례:** 같은 집안 안에서도 빈한 20% · 보통 50% · 넉넉 20% · 부유 8.5% · 거부 1.5% 로 갈리고(처음 재물 · 가산 · 신용 · 건강),
  외동 · 장자 · 둘째 · 막내로 태어난다. 장자 · 외동은 부모가 모두 떠날 때 가산(돈 · 집 · 가업)을 물려받고, 나머지는 3할만 받는 대신 집을 떠날 자유가 있다.
  세가 · 문파 속가의 장자는 후계 지목 · 동생과의 다툼 · 가주 승계를 겪는다. 세가는 본거지에서만 태어난다
  (사천당가 · 하북팽가 · 하북 모용세가 · 강남 남궁세가 · 호북 제갈세가) — 사천당가 장남은 약 13,000명 중 한 명꼴.
  - **직업 단계** — 직업 26종과 집안의 일(농가 · 상인 · 장인 · 어촌 · 사냥꾼 · 아전 · 유목민)마다 3~5단(예: 견습의 → 의원 → 명의 → 신의 → 어의,
    농부 → 자작농 → 부농 → 대지주). 해마다 경력이 쌓이고(그 직업의 스텟 · 생업 우선 1.4배), 셋째 단부터와 **꼭대기 단은 벽** —
    그 일의 큰일을 해내면 공적이 하나 쌓이고 **공적 하나에 시도 한 번**. 단마다 벌이 x1.7 · 2.8 · 4.2 · 6, 높은 단 전용 사건(`jrank`), 칭호.
    가만히 산 사람의 마흔 넘어 단: 첫째 7% · 둘째 21% · 셋째 51% · 넷째 21% · 다섯째 0%.
  - **재산** — 집(초가집 · 기와집 · 상가 건물 · 장원, 땅값이 출렁임) · 투자(전장 예금 · 상단 지분 · 광산 지분).
    명성 · 재물로 벼슬 사기 · 의연금도 된다.
  - **사업은 하는 일에서 자라난다**(11-07): 그 일의 둘째 단부터 "지금 하기" 에서 자기 사업을 차리고 · 키우고(3단) · 접는다
    (`GhD.JOB_BIZ` — 의원은 의방, 무관 사범은 무관, 도굴꾼은 도굴 길드, 수적은 수채 …). **관직(포졸 · 포쾌 · 금의위 · 동창 · 무관 ·
    무림맹 순찰 · 역관)과 승려 · 책사 · 일꾼은 사업이 없다.** 일을 바꾸면 사업은 정리된다(`GhLife._biz_follow_job`).
  - **문파의 자리**(11-07): 문파에 몸담은 무림인은 그 쪽의 자리가 일이다 — 외문 제자 > 내문 제자 > 대제자 > 장로(정파),
    방계 무사 > … > 가문 장로(세가), 교도 > 향주 > 당주 > 장로(신교), 일결 > 삼결 > 육결 > 구결(개방) …(`JOB_RANKS` 의 `sect:<쪽>`).
    공적 대신 **경지**가 벽이고(`SECT_REALM` — 대제자 일류, 장로 절정), 단이 오를수록 녹봉이 는다(`SECT_PAY_K`).
    **문파 찾아가기**에서 떨어져도 근골이 괜찮으면 **속가 제자**로 받아 주기도 한다 — 수련이 더디고(x0.75) 이류에 올라야 정식 제자가 된다.
    정파 · 세가 · 개방의 일류에게는 **무림맹**이 사람을 보낸다(`murim_join`) — 맹의 순찰 > 순찰대장 > 집법당 무사 > 맹의 장로, 그 위가 맹주 선거.
    셋째 단에 오르면 **직책**(집법당 · 전공당 · 외당 · 장경각)을 맡고, 문파가 해마다 **임무**(산채 소탕 · 호위 · 실종 제자 · 정탐 · 서신 · 역병)를 맡긴다.
  - **무림인의 벌이**: 녹봉은 적지만 이긴 싸움의 전리품, 해마다 보물 · 영지 · 비급을 찾을 기회. **기연은 돌아다니는 사람이 만난다**
    (눌러사는 사람 0.55배 · 무림인과 객잔 · 기루 같은 일터 1.3배 · 떠도는 직업 1.4배). 객잔 · 기루 · 나루 같은 일터는 무림 손님이 잦아 기연이 많지만 무공은 안 준다.
    **재능 없는 사람에게는 무공을 주는 기연이 안 온다**(근골 조건) — 설삼을 먹어도 몸만 낫는다.
  - **비무대회는 대회 판이 상대를 정한다**(`GhLife.TOURNEY_FIELD` — 예선 이류 · 본선 일류 · 사강 절정 · 결승 절정~초절정).
    예전에는 상대가 내 경지 ±1 이라 이류든 절정이든 우승 확률이 같았다.
  - **혼처는 바로 혼인하지 않는다**(11-07): 중매로 상대(집안 · 성품 · 초상 `gh_mate_*`)를 소개받아 교제하고, 한 해 넘게 사귀면
    해마다 혼인을 청할지 · 교제만 이어 갈지 · 헤어질지 묻는다.
  - **직업 도감**(처음 화면 → 도감 → 직업): 직업마다 조건(`GhD.job_need_text` — 조건표에서 그대로 만든다) · 벌이 · 단 · 사업.
  - 무림인은 경지에 따라 해마다 보수를 받고(`GhD.MART_PAY`), 호위 의뢰로도 번다.
  - **탈것**(나귀 · 노새 · 준마 · 마차 · 사인교 가마 · 나룻배 · 상선 · 한혈마 — 원작의 자동차 자리, 11-07): 진로 배수가 붙지만
    해마다 값이 깎이고 유지비가 나가며(못 내면 팔아 치움), 짐승은 늙어 죽거나 도둑맞고, 배는 뱃삯을 벌고 상선은 가라앉기도 한다.
  - **물건은 맞바꿈입니다**(11-07): 한쪽 길로 당기는 만큼 다른 길에서 멀어진다(목검 = 무공 x1.6 · 글공부 x0.75 · 위험 x1.1).
    좋은 것만 붙던 시절엔 전부 사는 게 정답이었다. 효과 글은 배수에서 그대로 만들고(`GhD.effect_text`), 가진 것을 누르면 버린다.
  - **물건 · 탈것**, 그리고 **인연**(부모 · 형제 · 단짝 · 배우자 · 사부 · 의형제 · 자식 — 성향이 있고 정이 깊을수록 그쪽으로 끈다). 셋이 사건 꼬리표
  (`entry` · `civil` · `trade` · `luck` · `meet` · `danger` · `vice` · `train`)의 배수를 곱합니다(`GhLife.mul`, 6배 상한).
  인연 창 · 할 일 창 아래 "지금 진로의 기운" 에 그 배수가 그대로 나옵니다.

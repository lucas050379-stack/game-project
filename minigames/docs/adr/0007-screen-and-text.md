# ADR-0007: 화면은 짧은 변 720, 가로가 기본 — 글자는 20px 이상, Jua 에 없는 기호 금지

- **상태:** 채택 (지금 동작 기준, 2026-11-09)
- **층:** Presentation

## 결정
- 기본은 **가로 1280×720**(11-04 사용자 결정). 허브가 창 방향을 보고 캔버스를 1280×720 / 720×1280 으로 바꿉니다(`Hub._fit_canvas`) — **짧은 변은 늘 720**.
- 화면마다 `wide()` 갈래: 가로는 "늘리기" 가 아니라 **좌우 정보창**.
- **캔버스 20px 미만 글자 금지.** (처음 근거는 "폰에서 절반으로 보임" 이었지만 11-09 부터 폰은 고려하지 않습니다 — [ADR-0012](0012-desktop-web-only.md).
  기준은 데스크톱 브라우저 창에서 읽히는가. 세로 배치는 새로 짜지 않아도 됩니다.)
- **화면 글자에 Jua 에 없는 기호(가운뎃점 · 줄표 · 곱하기 · 화살표) 금지** — 웹에서 네모로 나옵니다.

## 예외
- 아르카나 컬렉션은 **세로 화면을 확인하지 않습니다**(사용자 지시 11-08).

## 지키는 곳 (11-09 통일)
- 글꼴은 `UiKit.font()` 한 벌, 기호 바꾸기 표는 `UiKit.GLYPH_SWAP` · `UiKit.clean` 하나.
- 다섯 게임의 글자 그리기가 지납니다: 젤리팝 · 강호 · 아르카나 · 허브는 `G2.text_mid`, 스카이 `SaG2.text*`, 러너 `WrIcons.clean`, 강호 `GhArt.text`.
  젤리팝 `G2.text_mid` 는 그래도 남는 글자를 디버그 실행에서 stderr 에 알립니다.
- 아르카나 `main.gd` 는 `draw_string` 을 직접 부르는 곳이 13군데라 표를 안 지납니다 — 지금 그 글에는 금지 기호가 없습니다(11-09 확인). 새 글은 처음부터 안 쓰기.
- 이 통일로 강호일생의 "재산 ○냥 (집 · 투자 · 사업을 판 값)" · "난세에 태어났다 (위험 · 무공의 길이 잦다)" 같은 글이 웹에서 네모로 나오던 것이 고쳐졌습니다.

## 아직 어긋난 곳
- 아르카나에 캔버스 15~19px 글자가 있습니다(수집판 꼬리표 · 알림 줄 · 상대 이름) — [review #14](../review-2026-11-09.md).

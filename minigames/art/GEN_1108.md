# 11-08 그림 생성 목록

11-07 아침에 Cloudflare 하루 한도(1만 뉴런)에 걸려 한 장도 못 뽑았다. 아래 순서로 뽑는다.
하루에 대략 100~160장이 나오므로 **1번만으로 하루치를 거의 다 쓴다.** 2번은 남으면, 아니면 그다음 날.

## 시작 전

한도는 UTC 자정(한국 09:00) 근처에 풀리지만 정확하지 않다(11-06 은 09:53 에 풀렸다).
대시보드가 0 으로 보여도 믿지 말고 **한 장으로 먼저 시험**한다.

```
cd minigames
art\gen.bat gh_title
```

## 1. 강호일생 — 56종 × 2장 = 112장

```
bash art/gen_many.sh "^gh_" 2 2 8
```

프롬프트는 `art/prompts.txt` 의 `@gink`(수묵 담채) 줄. 후처리는 전부 `plain`(배경 · 삽화).

| 묶음 | 이름 | 쓰는 곳 |
|---|---|---|
| 화면 | `gh_title` · `gh_card` · `gh_board` | 처음 화면 · 허브 카드 · **인생 화면 전체 배경**(11-07 새로) |
| 출생 | `gh_birth_farm` · `fisher` · `hunter` · `town` · `scholar` · `palace` · `steppe` | 태어나기 화면 · 집안 장면 |
| 장면 | `gh_sect_jeong` · `sa` · `ma` · `saeoe` · `gh_clan` · `gh_beggar` · `gh_barracks` · `gh_escort` · `gh_wander` · `gh_office` · `gh_hermitage` · `gh_war` · `gh_grave` | 삽화 칸 (문파 · 관아 · 묘비 …) |
| 직업 13 | `gh_job_doctor` · `smith` · `inn` · `pleasure` · `scholar` · `assassin` · `hunter` · `gamble` · `temple` · `river` · `tomb` · `labor` | 직업을 가지면 삽화 칸(11-07 새로 · `GhArt.JOB_SCENE`) |
| 전환점 | `gh_m_*` (입문 · 대성 · 기연 · 혼인 · 첫아이 · 급제 · 장문인 · 우승 · 복수 · 참전 · 주화입마 · 승급 · 사업 · 파산 · 별호 …) | 큰 삽화 창 |

뽑은 뒤: 이름마다 하나 고르기(`tools/contact.gd` 로 한 줄에 늘어놓기) → `art/post.bat <원본> <이름> plain` →
`godot --headless --path . --import` → 테스트 빌드로 확인.
**그림이 없으면 코드가 그린 수묵 산수로 돌고**, `gh_board` · `gh_job_*` 는 그림이 있을 때만 쓴다.

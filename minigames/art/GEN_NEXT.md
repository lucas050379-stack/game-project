# 다음에 뽑을 그림 (11-08 정리)

프롬프트는 전부 `art/prompts.txt` 에 있고, 뽑기 · 후처리 방법은 다른 게임과 같다.

```
bash art/gen_many.sh '<이름 정규식>' <보스 장수> <나머지 장수> <동시 요청 수>   → art/source/ 에 후보
godot --path . --script res://tools/contact.gd -- ...                         → 후보를 한 장에 늘어놓고 고르기
post.bat art/source/<후보>.jpg <이름> plain                                   → art/<게임>/<이름>.png
godot --headless --path . --import                                            → 넣은 뒤 꼭(안 하면 오류 없이 코드 그림으로만 나온다)
```

- **뽑기 전에 `git pull` 과 `art/<게임>/` 을 먼저 본다.** 다른 곳에서 이미 뽑아 넣은 것을 모르고 다시 뽑아 한도를 쓴 적이 있다.
- Cloudflare Workers AI 무료 한도는 하루 1만 뉴런이다. 하루에 대략 **150장 안팎**이 뽑힌다. 막히면 30분쯤 뒤 한 장으로 시험한다.
- `ac_` 로 시작하는 이름은 `post.gd` 가 `art/arcana/` 에 넣는다(11-08 추가).
- `em_` 로 시작하는 이름은 `post.gd` 가 `art/empire/` 에 넣는다(11-09 추가).
- `rs_` 로 시작하는 이름은 `post.gd` 가 `art/redstar/` 에 넣는다(11-09 추가).

### 영웅은 한 장만 뽑는다

움직임(숨쉬기 · 위쪽 흔들림 · 빛줄기)은 코드가 준다(`AcArt.hero_portrait`). 프레임을 여러 장 뽑으면 장마다 얼굴 · 옷이 달라져 떨어 보인다.

고를 때 볼 것:
- 상반신이 정면이고 한 사람만 있다.
- 머리 위 · 어깨 둘레에 여백이 있다. 위쪽이 좌우로 살짝 흔들리므로 가장자리에 잘린 것이 있으면 티가 난다.
- 손이 얼굴을 가리지 않는다.
- 글자가 없다.

### 성물은 카드마다 다르다

목록은 `AcD.deck()` 에서 뽑았다. 물건 · 단계 · 자원이 게임 카드와 그대로 맞는다. **`AcD.GLYPHS` 순서를 바꾸면 이 목록도 다시 만든다.**

- 자원 색이 한눈에 읽혀야 한다: 화염 = 붉은 불꽃, 물 = 푸른 물방울, 숲 = 초록 잎, 빛 = 흰 금빛, 그림자 = 보랏빛 연기.
- 단계: 견습 = 소박한 물건, 장인 = 정교한 무구, 전설 = 신화의 보물.
- 카드 그림 칸은 가로가 조금 긴 네모다. 정사각으로 뽑아 가운데를 잘라 쓰니, **물건이 가운데에 있고 둘레가 비어 있는 것**을 고른다.
- 손 · 사람 · 글자가 들어간 것은 버린다.

### 진행 (11-08)

- **1일째 끝남.** 영웅 10명 · 허브 카드 · 화염 · 물 성물 36종을 골라 `art/arcana/` 에 넣었다(47장, 후보 142장).
  - 1일째 분량으로 하루 한도를 다 썼다.
- **남은 것은 2일째**(숲 · 빛 · 그림자 성물 54종 + 배경 2종)이다. 한도가 풀리면 아래 2일째 두 줄을 돌린다.
- 영웅 움직임을 지금 방식(그림 한 장 + 코드)으로 둘지, 진짜 GIF(유료 이미지→동영상 AI)로 갈지는 사용자가 테스트 빌드를 보고 정한다.

### 순서 (하루 150장 안팎 기준)

```
1일째  bash art/gen_many.sh '^ac_hero_' 4 4 8          # 40
       bash art/gen_many.sh '^ac_card$' 4 4 4          # 4
       bash art/gen_many.sh '^ac_r_[01]_' 2 2 8        # 화염 · 물 36종 × 2 = 72
2일째  bash art/gen_many.sh '^ac_r_[234]_' 2 2 8       # 숲 · 빛 · 그림자 54종 × 2 = 108
```

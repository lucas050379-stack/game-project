# 규칙 — 세계마뷸 절(CLAUDE.md)의 그림 규칙을 그림으로 옮기면서 지켜야 하는 것들.
# - **랜드마크는 원래 색으로 뽑고, 소유자 색이 들 부분(지붕 · 돔 · 조각상)만 순수 청록 #00FFFF 로 칠한다.**
#   게임이 청록만 소유자 색으로 바꾼다. 예전에는 흰 도자기 한 색으로 뽑아 통째로 칠했는데 "단색이라 별로"였다(11-04).
#   그래서 청록 말고는 파랑 · 청록 · 물을 아예 못 쓰게 했다(바꿀 부분과 섞이면 안 된다).
# - 건물(별장 · 빌딩 · 호텔)은 아직 흰 도자기 한 색 방식이다 — 쓰기 전에 랜드마크처럼 바꿀지 정한다.
# - **국기는 뽑지 않는다.** 이미지 모델은 국기 문양을 틀리게 그린다 — 국기는 지금처럼 코드로 그린다.
#   랜드마크에도 깃발 · 글자를 넣지 않는다.
# - **말(캐릭터)은 전신 치비 캐릭터 넷**(뽑아 둠 — 은발 베레모 · 비행모 소년 · 두건 · 뒤로 쓴 캡). 흰 옷은
#   tools/runner_art.gd 가 마스크로 떼어 플레이어 색으로 칠한다. 키 아트에 넣을 때도 이 넷으로 그린다.
# - **랜드마크는 받침대째로 와도 된다** — 게임이 그림 아래 끝을 칸 바닥에 붙인다(금빛 받침 · 그림자 없음).
# - 도쿄 타워 · 일본 관련 그림에 붉은 원 · 방사선 무늬 배경을 넣지 않는다.
# - 주사위는 뽑지 않는다 — 눈 개수를 틀리게 그리는 일이 잦고, 틀린 주사위는 게임이 거짓말을 하는 것이다.
# - 후처리: 물건 · 말 · 특수칸 = sprite, 바닥 = tile, 키 아트 = plain.
#   예) bash art/post_picks.sh art/runner_picks.txt  (고른 번호를 적은 목록 — sky_picks.txt 와 같은 꼴)
# - **화면 방향(세로 전용 / 가로 지원)을 정하기 전이다.** 물건 그림은 방향과 상관없지만,
#   키 아트(runner_card)는 세로로 뽑는다(허브 카드가 정사각이라 가운데만 잘라 쓴다).

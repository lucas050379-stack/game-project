# ADR-0002: 허브는 끝까지 살고 게임 화면만 갈아 끼운다

- **상태:** 채택 (지금 동작 기준, 2026-11-09)
- **층:** Foundation

## 맥락
`change_scene` 으로 장면을 통째로 바꾸면 효과음 · 배경 음악 · 순위 요청이 붙은 노드가 같이 지워지고,
게임을 다시 열 때 static 변수가 지워진 노드를 가리켜 깨졌습니다.

## 결정
- `main.tscn` 에는 허브 하나. 게임 화면은 허브가 자식으로 열고 닫습니다.
- 오래 사는 노드는 `Hub.host(self)` 에 붙이고, 게임에서 나갈 때는 `Hub.leave(self)` 하나만 부릅니다.
- 허브 없이 단독으로 돌면 `leave` 가 그냥 앱을 끝냅니다.

## 결과
- 새 게임의 소리 · 네트워크 노드도 `Hub.host` 로 붙입니다.
- 검사: `run.bat -- --hub-test` (다섯 게임을 열고 닫고 두 게임을 다시 엶).
